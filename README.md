# Customer Churn Prediction

## Project Overview
This project uses machine learning to predict whether a telecom customer is likely to leave the company.

## Dataset
Telco Customer Churn dataset.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Logistic Regression
- Jupyter Notebook

## Project Workflow
1. Loaded and explored the customer dataset.
2. Cleaned the data and handled missing values.
3. Performed exploratory data analysis using charts.
4. Converted categorical data into numerical features.
5. Split the data into training and testing sets.
6. Trained a Logistic Regression model.
7. Evaluated model performance.

## Project Files
- `CUSTOMER CHURN PREDICTION.ipynb` — Project code and analysis
- `customer_churn_model.pkl` — Saved machine learning model

## Outcome
The model predicts customer churn based on customer information. The notebook contains the model evaluation results.
